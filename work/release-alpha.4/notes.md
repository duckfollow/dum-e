## Dum-E v0.1.0-alpha.4

- Read PostgreSQL enum values in table previews and SQL results. Edit enum cells using the database-defined choices.
- Edit PostgreSQL JSON and JSONB cells with a multiline editor, formatting, and separate SQL NULL handling.
- Right-click a column header in Table Preview to filter or sort the whole table before pagination. Clear either condition from the same menu.
- Database Relations has a refreshed layout and keeps the diagram visible while refreshing.
- Collapse SQL Editor to give Results more space.
- Align connection menu actions consistently.

### Install

Download the Apple Silicon DMG and drag Dum-E into Applications. Quit Dum-E before replacing the app. This build is ad-hoc signed and is not notarized by Apple.
