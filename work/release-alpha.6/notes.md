## Dum-E v0.1.0-alpha.6

- Edit one or more rows directly from SQL Results for PostgreSQL queries that select from one table and include its full primary key. Double-click a cell or select rows and choose Edit rows.
- Save changes together and refresh Results automatically in a read-only transaction. If refresh fails, the grid keeps the previous results and offers a retry.
- Single-statement results open directly in the grid. Save and Discard stay visible on the right for editable results.

### Install

Download the Apple Silicon DMG and drag Dum-E into Applications. Quit Dum-E before replacing the app. This build uses ad-hoc signing and has not been notarized by Apple.
