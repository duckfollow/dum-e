## Dum-E v0.1.0-alpha.5

- Preview PostgreSQL arrays and other types such as intervals and network addresses in table grids and SQL results.
- Read array elements at a glance, including empty arrays, nested arrays, and NULL elements. Edit arrays in eligible table grids using PostgreSQL array literals.
- See why a table is read-only directly in the grid toolbar.
- Close all workspace tabs from the tab actions menu. Dum-E prompts you to resolve pending table edits before closing.

### Install

Download the Apple Silicon DMG and drag Dum-E into Applications. Quit Dum-E before replacing the app. This build uses ad-hoc signing.
